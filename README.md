# Oleo Card Pro

Minimal sales page for custom Apple Wallet card skins.

## Live site
Deployed on Vercel.

## Downloadable software
The product is a digital download containing:
- Browser-based card maker
- Sample high-res skins
- Usage guide

Real Mac app version would require the AirCard-style USB exploit (patched by Apple in iOS 27.2 beta 3+).
